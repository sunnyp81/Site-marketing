## What Sunny has to do personally

Five items. Ordered so nothing gets squatted before you can move.

1. **Reserve @sitemarketing handles across platforms** — Register the handle (or closest consistent variant) on LinkedIn, X, YouTube, GitHub, Bluesky, Reddit, Substack/beehiiv and Product Hunt before any public launch activity.
   *Why:* Handles are unrecoverable once squatted, cost nothing today, and the LinkedIn launch sequence and newsletter both assume consistent naming.

2. **Buy 2-3 defensive adjacent domains** — Check availability and purchase the obvious typo/adjacent set (e.g. sitemarketing.com if attainable, website.marketing, sites.marketing) and 301 them to site.marketing.
   *Why:* Cheap insurance against confusion and competitor squatting, and redirects consolidate any stray type-in traffic and links to the canonical domain.

3. **Trademark clearance search** — Run a knockout search (USPTO/UKIPO/EUIPO) on 'site.marketing' and the chosen grader and newsletter names before publishing the landing pages; file if clear and budget allows.
   *Why:* Renaming a tool or newsletter after launch destroys accumulated citations and links — exactly the assets the whole strategy exists to build.

4. **Create the measurement accounts** — Set up GA4 property, Google Search Console, Bing Webmaster Tools, and an account with one citation-monitoring tool (or commit to the DIY 20-prompt cadence); connect billing where needed.
   *Why:* The measurement-setup guide can specify configuration but only the owner can create accounts and verify domain ownership — and without day-zero baselines the 'Measure first' doctrine is unprovable on our own site.

5. **Line up the grader build resource** — Decide who builds the 20-prompt audit tool and Grader (yourself, contractor, or defer) and confirm API budget for the LLM calls the visibility module requires.
   *Why:* Both product specs are shippable documents, but the tools only become the data-collection moat once someone commits build time and API spend.
